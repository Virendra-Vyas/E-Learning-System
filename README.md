# E-Learning System

A full-stack web application for managing students, courses, 
and academic records. Built with ASP.NET Core MVC and SQL Server.

## Features

- Student registration and account management
- Course enrollment and management
- Grade tracking and academic records
- Admin dashboard for system management
- Role-based access control (Admin / Student)
- Responsive UI with Bootstrap

## Tech Stack

- **Backend:** ASP.NET Core MVC / C#
- **Database:** SQL Server / Entity Framework
- **Frontend:** HTML5, CSS3, Bootstrap, JavaScript
- **Auth:** ASP.NET Core Identity

## Setup

1. Clone the repository
2. Update connection string in `appsettings.json`
3. Run database migrations: `Update-Database`
4. Build and run the solution
